# Changelog

## 0.1.0 — initial public release

Release status: preparation in progress.

- Android sender using Camera2, MediaCodec H.264, and RTP/H.264 over UDP.
- Linux x86_64/amd64 OBS source with VAAPI/DRM PRIME and CPU fallback.
- Downloadable Android APK and Linux OBS plugin planned as release artifacts.
- Trusted-LAN deployment without authentication or encryption.
