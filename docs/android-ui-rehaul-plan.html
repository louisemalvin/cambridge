Decisions to annotate

Dim behavior

Recommended: a reversible black scrim over the preview. It is local to the UI, survives stream lifecycle changes, and does not alter camera or session behavior. Use the standard BrightnessLow and BrightnessHigh icons, not a moon glyph.

Zoom placement

Recommended: pinch plus a compact zoom chip/tray on the main surface. The full slider remains in settings.

Pre-connection preview

Recommended: waiting state only until a receiver starts the negotiated session. A live local preview needs a separate camera ownership design.

Implementation guardrails

Do not change the receiver protocol, RootEncoder ownership, negotiated stream dimensions, or camera-neutral session interfaces for this UI pass.

Replace the current screen-level vertical scroll with a fit-to-window preview stage. Test portrait and landscape geometry, state overlays, settings visibility, dim toggling, and existing zoom bounds/reset behavior.

After the direction is confirmed, the proposal should become a compact .tasks contract before implementation starts.
